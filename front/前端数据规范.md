# 前端数据规范（发给设计同学）

## 一条铁律

> **HTML 里只留结构和样式，所有会变的文字/岗位/题目/报告，全部放进 `mock-data.js`。**

改岗位名称、改推荐文案、改任务题：**只改 `mock-data.js` 一个文件**，不要改 HTML 里散落的文字。

---

## 文件分工

```
front/
├── index.html            ← 页面入口（结构布局）
├── css/styles.css        ← 全部样式（设计同学主要改）
├── js/app.js             ← 后端 API + 数据（勿改）
├── js/ui.js              ← 交互逻辑（设计同学主要改）
└── 前端数据规范.md
```

---

## 什么放 mock-data.js

| 放 mock-data | 不放（留在 HTML） |
|--------------|-------------------|
| 五个岗位名称、简介、标签 | 按钮、布局、颜色、动画 |
| 推荐卡片文案 | `.screen` 页面结构 |
| 任务题目、选项、情境 | `data-go` 跳转逻辑 |
| 报告结论、优劣势 | 拖拽、连线等交互代码 |
| 表单选项（chip 列表） | |

---

## 岗位必须用 jobId

后端统一 ID（**不要自己发明**）：

| jobId | 显示名 |
|-------|--------|
| `ai_product` | AI产品 |
| `ai_ops` | AI运营 |
| `ai_data_eval` | AI数据与评测 |
| `ai_app_dev` | AI应用开发 |
| `ai_ui_design` | AIUI设计 |

HTML 里给卡片加：`data-job-id="ai_product"`，**不要**在 5 个地方各写一遍「AI 产品经理」。

---

## 禁止事项

- ❌ 在 `#roles`、`#recommend`、`#report` 各写一套岗位名
- ❌ 改岗位名要搜全文替换
- ❌ 报告里写「最适合」「适配潜力」——改用「本轮证据」「值得继续体验」

---

## 页面怎么渲染（示例）

HTML 里岗位列表改成空容器：

```html
<div class="roles" id="rolesList"></div>
```

JS 里从数据渲染（只写一次）：

```javascript
const list = document.getElementById('rolesList');
APP_DATA.jobs.forEach((job, i) => {
  list.insertAdjacentHTML('beforeend', `
    <article class="fan-card" data-job-id="${job.jobId}">
      <span class="fan-number">${String(i + 1).padStart(2, '0')}</span>
      <h2>${job.name}</h2>
      <p>${job.shortDesc}</p>
      ...
    </article>
  `);
});
```
