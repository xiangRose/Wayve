# WAYVE 产品总览

状态：CURRENT PRODUCT SOT — APPROVED FOR FEISHU SOT
来源：Feishu，本地投影
更新时间：2026-08-29

## MVP Scope Cut Override

Current MVP Hard Skill is Scenario-based Hard Skill Assessment. Work-sample-based Hard Skill architecture is Future / Post-MVP. Journey: Entry → Optional Profile → Five Role Exploration → Hard Skill Scenario Quiz → Collaboration Sprint → Reflection → Integrated Report → Next Mission.

## 产品定义

WAYVE 是一个基于 **Preview before Commit（先体验，再承诺）** 的职业探索产品。用户可以体验真实的 AI 时代工作，观察自己的行动，获得有边界的专业准备度评估，理解岗位实际工作方式，并选择下一步验证实验。

WAYVE 不是心理测评、简历匹配器、招聘测试或职业结论系统，不判断永久能力、潜力或职业适配度。

## Core Exploration Cycle

`Entry → Optional Profile → Five Role Exploration → Hard Skill Scenario Quiz → Collaboration Sprint → Reflection → Integrated Report → Next Mission`

Scenario Quiz 是 MVP 的专业判断证据来源；Work Sample 是 Future / Post-MVP 架构。Collaboration 提供跨岗位协作情境。跳过 Collaboration 时记录为 `not_observed`，不产生负面能力判断，并限制 Working Portrait 的 claim。Current MVP 可将新 Next Mission 记录为 `pending`。

## 产品原则

- Recommendation 只用于导航；
- Profile 可选；
- Background、Task Evidence、Collaboration Evidence、Interest、Reflection 分开保存；
- Work Sample 是真实工作，不是知识考试；
- Behavior 只有经情境化 Replay 才能形成 Evidence；
- Hard Skill Readiness 只描述本次被观察的岗位工作；
- `not_observed` 没有 performance score；
- 一次体验不能推出稳定人格、稳定特质或趋势；
- 用户拥有最终职业决定权；
- AI 不得制造 Evidence 或隐藏的确定性职业结论；
- Next Mission 必须来自 evidence gap / unknown。

## 五个岗位

`ai_product`、`ai_ui_design`、`ai_ops`、`ai_data_eval`、`ai_app_dev` 是唯一 active role IDs，五岗平等可选。

## 体验层级

Demo、Standard、Extended 是关于体验深度和认知负担的产品假设，不是 SLA 或验收时长。
